ABOUT THE PRODUCT

A narrow tool for a real closeout task.

M2 AI, LLC builds focused software that works inside platforms people already use. Closeout Readiness Check is designed for electrical subcontractor project managers who want one more structured review before handing over a closeout folder.

Why it is deliberately limited

The first version checks seven published baseline categories with deterministic rules. It does not interpret a contract, search outside the selected folder, read image-only documents, or declare a package complete. Those limits are visible because false certainty would be worse than an honest human-review flag.

How it earns trust

Readable matches cite the local source. Unreadable files and incomplete scans remain uncertain. Files are scanned locally. Findings and cited excerpts are returned to Claude; project documents are not uploaded to M2 AI's billing service. The hosted service handles activation identifiers, entitlement verification, and Stripe billing.

What the baseline covers

The first release looks for seven electrical closeout categories: as-built one-lines or risers, panel schedules, acceptance-testing records, O&M manuals, warranties, spare parts or attic stock, and training records. When a category expects timing evidence, the check looks for a real calendar value near the applicable label in the same readable source. It never treats a year alone as sufficient.

What the baseline cannot decide

Every project has its own contract, specifications, revisions, approvals, and owner expectations. The tool cannot know whether a document is authentic, signed, current, contractually required, or acceptable to the receiving party. It also cannot read image-only files in the first release. Those boundaries are why the report uses cited statuses and repeatedly directs the user back to a person.
