Support

For installation, activation, billing, or recovery-key help, email rmach816@outlook.com.

Before contacting support

  • Confirm you are using Windows Claude Desktop and the official extension.
  • Rerun the check on the purchasing computer after Checkout; it activates automatically.
  • For another computer, use the recovery/company key from your confirmation page or ask support for help.

Billing

You can open the Stripe customer portal from Manage billing to cancel at period end or update payment details.

If a check will not start

Confirm that the folder selected in the extension settings still exists and that your Windows user can open it. The product does not follow symbolic links or scan outside the selected folder. A failed check should not consume the one free completed check. Copy the exact error text into your support message, but do not attach the project folder or any project document.

If the report requires human review

That status is expected when a plausible file is image-only, unreadable, truncated, or outside a complete scan. It is not a billing or installation failure. Open the cited path yourself and compare it with the controlling contract, specifications, and owner requirements. The first release deliberately has no OCR and cannot determine whether a document is signed, current, authentic, or acceptable.

Privacy and security

Project content stays on the computer. Support does not need project documents, recovery keys, private keys, or full card details. For a billing question, provide only the email used at Stripe Checkout and a short description of the issue. For a suspected security problem, describe the behavior without including sensitive project material.

Response and contact

M2 AI, LLC handles support by email. Include “Closeout Readiness Check” in the subject, the Windows and Claude Desktop versions, and whether the issue involves installation, the local check, activation, recovery, or billing. See the contact page for the current contact channel.
